# 생명의말씀선교회 USA 2027 모바일 달력

생명의말씀선교회 USA(https://www.jbchusa.org/) 2027 탁상달력의 **미주 전체 일정**을 휴대폰·PC에서 보는 4개 언어(한국어·English·Español·中文) 달력입니다.
달력 그림으로 **휴대폰·컴퓨터 배경화면**도 만들 수 있습니다. GitHub Pages로 **무료** 운영합니다.

- 주소: https://ilhwan-moon.github.io/2027-jbchusa-callendar/
- 언어별 링크: `/ko/` `/en/` `/es/` `/zh/` (또는 `?lang=ko|en|es|zh`)
- 검색엔진에는 나오지 않습니다(noindex). 링크를 받은 분만 볼 수 있습니다.

## 화면
1. **이달의 그림**과 말씀 (누르면 크게 보기)
2. **달력**: 행사는 색 띠로 이어서 표시하고, 공휴일은 빨간 글씨로 표시합니다. 날짜를 누르면 그날 일정이 보입니다. 옆으로 밀면 달이 넘어갑니다.
3. **이달의 행사 · 공휴일 · 다가오는 행사**: 「내 휴대폰 달력에 모두 넣기」(.ics 파일)를 지원합니다.
4. **배경화면 만들기**: 아이폰 / 안드로이드 / 윈도우 / 맥 크기로 만들 수 있습니다.
   - 종류: **달력 + 그림** 또는 **그림만**(이달의 그림 / 표지 / 뒤표지, 「화면 가득」 또는 「그림 전체(잘림 없이)」)
   - 배경: 이달의 그림(흐리게) / 그림 선명하게(휴대폰) / 별하늘 / 단색
   - 넣을 내용: 이달의 말씀, 행사 표시, 선교회 로고
   - **그림 위치 조정**: 「화면 가득」·「그림 선명하게」일 때 미리보기를 끌거나 좌우·위아래·확대 슬라이더로 원하는 부분을 고릅니다(기기·달마다 기억).
   - 휴대폰은 위쪽 시계·위젯 자리와 아래쪽 독 자리를 비워 둡니다. 미리보기에서 그 자리를 확인할 수 있습니다.
   - 휴대폰에서는 「사진에 저장하기」(공유 창), PC에서는 내려받기로 저장합니다. 기기별 설정 방법은 그림으로 안내합니다.

소식지 사이트와 같은 기능을 그대로 씁니다: 「가 가 가」 글씨 크기, 자동/밝게/어둡게, 홈 화면 바로가기(아이폰·안드로이드·카톡),
돌아올 때 사이트가 바뀌었으면 자동 새로고침.

## 행사 고치기
`data.js`만 고치면 됩니다.
- `EVENTS`: `{ s: '시작일', e: '끝나는 날', ko: '한국어', en: 'English', es: 'Español' }`
- `HOLIDAYS`: `{ d: '날짜', ko, en, es }`
- `MONTHS`: 달마다 인물, 주제, 말씀(개역한글 / NKJV / RVR1960 / 和合本), 테마색, 배경화면에서 그림을 자를 가로 위치(`focus`)

## 파일
| 파일 | 내용 |
|---|---|
| `index.html`, `styles.css`, `app.js` | 화면, 다국어, 달력, 설정 |
| `wallpaper.js` | 배경화면 이미지 만들기(canvas) |
| `data.js` | 말씀·행사·공휴일 데이터 |
| `img/art-01~12.jpg` | 이달의 그림(배경화면용 큰 그림), `-s`는 화면용 작은 그림 |
| `img/cover.jpg`, `img/back.jpg` | 달력 표지와 뒤표지(별하늘) |
| `sw.js`, `manifest*.webmanifest` | 홈 화면 앱 |

배포: `main`과 `gh-pages` 브랜치를 같게 유지합니다. Pages는 `gh-pages` 브랜치에서 배포합니다.
